# Session Learnings

Bitácora de sesiones con Claude. Cada archivo en este directorio documenta:

- **Qué se pidió** — resumen del objetivo de la sesión
- **Qué se hizo** — acciones concretas tomadas
- **Aprendizajes** — lo que funcionó, lo que no, y por qué
- **Feedback del usuario** — correcciones, preferencias explícitas, reglas nuevas
- **Para futuras sesiones** — patrones reutilizables, límites conocidos, preferencias a respetar

## Convención de nombres

`YYYY-MM-DD-slug.md` — un archivo por sesión. Si una sesión abarca varios días, crear uno por día o agregar sufijo `-part-N`.

## Cómo usar

Al terminar una sesión, Claude debería volcar acá los hallazgos antes de cerrar. Al empezar una sesión nueva, revisar los últimos 3-5 archivos para recuperar contexto y preferencias.
