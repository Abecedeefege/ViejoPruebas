# Aprendizajes — Informe diario de rugby uruguayo

Este archivo registra feedback del usuario sobre los informes diarios enviados a rugby@itamoa.com,
para que las próximas ejecuciones del task programado lo tengan en cuenta.

## Cómo se usa
Cada vez que el usuario da feedback sobre un informe (algo que sobró, faltó, un formato que no gustó,
una fuente poco confiable, etc.), se agrega una entrada abajo con fecha. Antes de generar un nuevo
informe, hay que releer este archivo.
