# Aprendizajes — Informe diario de rugby uruguayo

Este archivo acumula feedback del usuario sobre los informes diarios (rugby@itamoa.com) para mejorar las próximas ediciones. Antes de generar un nuevo informe, revisar esta lista.

## Cómo usar este archivo
- Cada vez que el usuario dé feedback sobre un informe, agregar una entrada abajo con fecha, qué se corrigió y la regla a futuro.
- Mantener las entradas cortas (1-3 líneas cada una).

## Contexto fijo del proyecto
- Fuentes prioritarias: uru.org.uy, xn--pearol-xwa.org (Peñarol oficial), obcyogc.com (Old Boys oficial, a veces en mantenimiento/sin noticias), ESPN Deportes, La Nación (AR), Montevideo.com.uy.
- Regla estricta: si no hay novedades de las últimas 24h para Peñarol / Old Boys / Los Teros, escribir literalmente "Sin novedades" — no rellenar con noticias viejas ni contexto de temporada.
- Los Pumas se reporta solo si la novedad involucra directamente a Los Pumas (partidos, convocatorias, resultados), no rugby internacional general.
- Tablas de posiciones: Súper Rugby Américas y Top 12 uruguayo — usar la fuente más reciente disponible y citarla; si el sitio oficial solo muestra la tabla como imagen, usar fuentes secundarias (ESPN, La Nación, Wikipedia) y aclarar la fecha/ronda a la que corresponde el dato.
- Destinatario del informe: rugby@itamoa.com.
- Nota técnica: el conector de Gmail disponible en este entorno solo permite crear borradores (create_draft), no enviar directamente. Cada informe se deja como borrador en Gmail para que el usuario lo envíe manualmente, salvo que se habilite una herramienta de envío.
