# Aprendizajes — Informe diario de rugby uruguayo

Este archivo registra feedback del usuario (andresbazzurro@gmail.com) sobre los informes diarios
de rugby (Peñarol Rugby, Old Boys, Los Teros, Los Pumas) para mejorar entregas futuras.
Cada entrada nueva se agrega al final, con fecha.

## Cómo se usa
- Antes de armar un informe, releer este archivo por si hay instrucciones o preferencias acumuladas.
- Cuando el usuario da feedback sobre un informe (formato, fuentes, tono, qué incluir/excluir,
  errores de datos, etc.), agregar una entrada acá con la fecha y el cambio aplicado.

## Notas operativas conocidas
- El buzón conectado (Gmail) solo permite crear borradores (`create_draft`), no hay tool de envío
  directo. El destino real es rugby@itamoa.com, pero el borrador se crea en la cuenta conectada
  (andresbazzurro@gmail.com) y hay que enviarlo manualmente, o el usuario debe confirmar/activar
  el envío automático si lo desea.
- Rugby uruguayo/regional tiene ciclo de noticias lento (no siempre hay novedades genuinas en
  ventanas de 24hs exactas). Regla vigente: reportar la novedad verificable más reciente con su
  fecha real citada, y usar "Sin novedades" solo cuando no se encontró nada relevante en varios días.
- Fuentes que fallan o bloquean fetch directo: obcyogc.com (en mantenimiento), pasionrugby.com.uy
  (bloquea con 403). Preferir búsquedas web + uru.org.uy + espn.com.uy/com.ar + montevideo.com.uy +
  elobservador.com.uy como alternativas.
