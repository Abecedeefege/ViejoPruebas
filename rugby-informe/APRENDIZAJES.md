Este archivo guarda feedback del usuario (andresbazzurro@gmail.com) sobre los informes
generados, para aplicarlo en las próximas ejecuciones. Antes de generar un nuevo informe,
leer este archivo completo.

## Cómo usarlo
- Cada vez que el usuario dé feedback sobre un informe (tono, formato, fuentes, algo que
  faltó, algo que sobró, un dato incorrecto, etc.), agregar una entrada nueva abajo con
  fecha, el feedback textual (o resumido) y la regla concreta que se desprende de él.
  Solo entradas de feedback real dado por el usuario en este chat u otro; no rellenar
  con contenido inventado.
- Las reglas activas se listan primero para consulta rápida; el historial completo queda
  debajo como respaldo.

## Notas operativas (no son feedback del usuario, son notas de proceso)
- El MCP de Gmail conectado solo tiene `create_draft`, no un `send` directo. Los informes
  se dejan como borrador dirigido a rugby@itamoa.com para que el usuario los revise/envíe,
  salvo que en el futuro aparezca una herramienta de envío directo.
- La URU (uru.org.uy) publica la tabla de posiciones del Top 12 como imagen, no como texto
  navegable — no confiar en scraping automático para esa tabla sin verificar visualmente.
- "Súper Rugby Américas": temporada 2026 con calendario regular de 14 fechas, terminó el
  19/6/2026 (campeón Pampas). Revisar si para 2027 cambia el calendario.
- Uruguay Top 12 se juega en dos fases (Apertura / Clausura) + una final entre ambos
  campeones de fase, similar al fútbol uruguayo — no es una tabla única de todo el año.
