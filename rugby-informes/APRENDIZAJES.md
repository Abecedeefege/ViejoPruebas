# Aprendizajes — Informe diario de rugby uruguayo

Este archivo guarda el feedback del usuario sobre los informes diarios para mejorar
las próximas entregas. Cada vez que el usuario dé una corrección o preferencia,
se agrega una entrada acá antes de generar el siguiente informe.

## Formato de entrada

```
### AAAA-MM-DD
- Feedback recibido: ...
- Ajuste aplicado: ...
```
