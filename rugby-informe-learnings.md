# Aprendizajes — Informe Diario de Rugby Uruguayo

Este archivo registra feedback del usuario sobre el informe diario de rugby (Peñarol Rugby, Old Boys, Los Teros) para ir ajustando fuentes, formato y criterios en próximas ejecuciones.

Formato de cada entrada:

```
## AAAA-MM-DD
- Feedback: <qué dijo el usuario>
- Ajuste aplicado: <qué se cambió en el proceso/prompt/fuentes>
```

## Notas de proceso (no son feedback del usuario, son observaciones operativas)

- El sitio oficial de Old Boys (obcyogc.com) estuvo "en mantenimiento" el 2026-07-02; no se pudo usar como fuente ese día.
- uru.org.uy no expone la tabla de posiciones del Top 12 en HTML estático fácilmente scrapeable vía WebFetch; conviene revisar si tienen una vista alternativa (PDF, API) o confirmar manualmente.
- El envío a rugby@itamoa.com se hace como **borrador de Gmail** (herramienta Gmail MCP disponible solo tiene `create_draft`, no un `send`). Si se necesita envío automático real, hay que revisar si existe otra vía (p. ej. otro conector con permiso de envío) o que el usuario confirme manualmente el envío del borrador.
